# Remote Mac KeepAwake v1.4.0

## English

This release makes Mac Pulse substantially more trustworthy during unattended
operation:

- every heartbeat is HMAC-SHA-256 signed with replay protection and online key
  rotation;
- Cloudflare Cron checks offline state every minute, persists retries, supports
  a fallback webhook, and can ping an external scheduler canary;
- the dashboard retains exact-timestamp battery-health, thermal, and opt-in
  network-diagnostic history;
- `remote-mac-keepawake upgrade --release latest` downloads over HTTPS,
  validates `SHA256SUMS` and archive paths, and rolls back failed upgrades.

There is still no software guarantee of permanent reachability: closed-lid
sleep, power/network loss, hardware failure, shutdown, and FileVault pre-boot
unlock remain outside the product boundary. Review the README before rebooting
a remote Mac.

## 简体中文

此版本显著提升了 Mac Pulse 在无人值守运行时的可信度：

- 每个心跳都使用 HMAC-SHA-256 签名，带防重放和在线密钥轮换；
- Cloudflare Cron 每分钟检查离线状态，持久化重试，支持备用 Webhook，并可向
  外部 scheduler canary 发送存活信号；
- 面板完整保留带准确时间的电池健康、温控和显式启用的网络诊断历史；
- `remote-mac-keepawake upgrade --release latest` 通过 HTTPS 下载，验证
  `SHA256SUMS` 与归档路径，升级失败时自动回滚。

软件仍不能保证电脑永久可达：合盖睡眠、断电、断网、硬件故障、关机和
FileVault 启动前解锁均不在产品控制范围。远程重启前请先阅读 README。

## Verification / 校验

```bash
shasum -a 256 -c SHA256SUMS
gh attestation verify remote-mac-keepawake-v1.4.0.tar.gz \
  --repo xudaniel/remote-mac-keepawake
```
